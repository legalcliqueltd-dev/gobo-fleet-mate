### 3. Fix SOS Email Not Sent to Admin

**Root cause**: The `sos-create` edge function creates the SOS record but never calls `sos-dispatch`. The `sos-dispatch` function expects a webhook-style `{ type, record }` payload (as if triggered by a database webhook), but no such webhook is configured.

**Fix**: After successfully creating the SOS event in `sos-create`, invoke `sos-dispatch` directly within the same function by calling it with `{ type: 'INSERT', record: sosEvent }`. This ensures the email is sent to both the admin and driver immediately after SOS creation, without requiring a separate database webhook configuration.

**File**: `supabase/functions/sos-create/index.ts` — add a `fetch()` call to the `sos-dispatch` function URL after the SOS record is created, passing the event data. Then redeploy both edge functions.
